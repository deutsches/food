# 口袋收藏

使用者在 Codex 對話提供 Threads 連結，由助理讀取文字與圖片，整理進 data/collection.json 與頁面。這是有來源的收藏網站，沒有宣稱網站能自動爬取 Threads。

美食：/；日本購物：/shopping。分類依使用者意圖，食品類伴手禮也可放購物頁。

未知地點、價格、幣別不推測。保留原文連結，图片存 public/images。新文章以 post id 去重。不得把代購 $ 價格視為日圓。

使用 pnpm dev、pnpm build。

價格為選填，使用者只需要名稱、圖片與原文的收藏記錄；不用額外查價。

## 收藏與分類規則
- 只讀使用者提供的作者貼文、圖片及同作者續文，不搜尋外部店家資訊或其他人的留言。
- 價格非必填；未知資訊留空。
- 美食頁使用分類、店名、地區、Google Maps 搜尋連結及原文出處的表格；購物維持獨立頁面。
- 地圖連結僅由已記錄店名與地區產生，不代表已核實位置。
- 自訂分類和店家分類存入 D1，依網站登入使用者區分。預設分類為披薩、燒肉、咖啡店、漢堡。
- 修改資料表後用 drizzle-kit generate 產生 migration，保留已發布的 migration 歷史。
